I love building tools that just work.

This account holds Python tools that each check one thing and fail CI when it is wrong. Standard library only, nothing extra to install. MIT licensed.

Tools people reach for most:

- [broken-link-checker-cli](https://github.com/haiderstudio/broken-link-checker-cli) — checks links in Markdown and HTML docs, and tells a missing page apart from a missing anchor.
- [secret-scan-skill](https://github.com/haiderstudio/secret-scan-skill) — scans the diff about to be committed for leaked secrets, and stops the commit if it finds one.
- [repo-hygiene-checker-cli](https://github.com/haiderstudio/repo-hygiene-checker-cli) — checks a repo has a README, licence, .gitignore, CI and issue templates before it goes public.
- [git-branch-cleanup-cli](https://github.com/haiderstudio/git-branch-cleanup-cli) — lists stale local branches and deletes them only when you say so.
- [json-formatter-validator-cli](https://github.com/haiderstudio/json-formatter-validator-cli) — formats and validates JSON, and points at the exact line and column when it is broken.

The full list is on the [repositories page](https://github.com/haiderstudio?tab=repositories).
