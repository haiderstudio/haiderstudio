# Haider Ali
Small, single-job developer tools. One job per repo, tested, free, MIT.
## What I build
- Agent skills that do one job well, with refusal rules for vague work.
- Python CLIs, standard library only, that run offline.
## Repos
- [readme-writer-skill](https://github.com/haiderstudio/readme-writer-skill) – README from real code, never invented features.
- [git-branch-cleanup-cli](https://github.com/haiderstudio/git-branch-cleanup-cli) – delete stale branches, dry-run first.
- [env-example-sync-cli](https://github.com/haiderstudio/env-example-sync-cli) – .env.example drift check, fails CI.
- [sitemap-audit-skill](https://github.com/haiderstudio/sitemap-audit-skill) – sitemap + robots audit, only checks actually run.
- [markdown-table-converter-cli](https://github.com/haiderstudio/markdown-table-converter-cli) – CSV/JSON to Markdown tables, both ways.
- [commit-message-skill](https://github.com/haiderstudio/commit-message-skill) – Conventional Commits from a real diff.
- [broken-link-checker-cli](https://github.com/haiderstudio/broken-link-checker-cli) – broken page vs broken anchor links.
- [changelog-writer-skill](https://github.com/haiderstudio/changelog-writer-skill) – Turn a git log and a release range into a Keep-a-Changelog entry — with no invented features.
- [seo-meta-audit-skill](https://github.com/haiderstudio/seo-meta-audit-skill) – Audit one page's SEO basics — title, meta description, canonical, Open Graph, and H1 structure — and report only what the page actually shows.
